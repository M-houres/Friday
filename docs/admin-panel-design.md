## 每页内容

### 1. 总览看板
- 4个核心指标卡片：今日任务 / 活跃用户 / 今日成本 / 今日收入
- 7天趋势折线图（任务量、成本、用户）
- 实时状态条：Agent健康 / 熔断器 / 队列积压
- 最近10条活动时间线
- 快捷操作：新建Agent / 提交测试任务

### 2. 用户管理
- 表格：头像、昵称、邮箱、注册时间、套餐、最后登录、任务数
- 搜索/筛选/排序/分页
- 点击用户：详情弹窗（使用统计、任务历史、操作日志）
- 操作：禁用/启用/删除/修改套餐/重置密码
- 批量操作：导出/群发通知
- 角色：管理员 / 普通用户 / API用户 / 自定义角色
- 邀请：生成邀请链接 + 批量导入

### 3. Agent 管理
- 卡片网格：名称、状态指示灯、模型、工具数、最近活跃
- 创建表单：名称/系统提示词/模型/策略/工具勾选
- 编辑：修改配置，实时保存
- 对话调试：侧边栏打开聊天窗口，实时测试Agent
- 复制/删除/导出配置

### 4. Skill 市场
- 已安装列表：名称、版本、工具数、启用开关
- 模板库：PPT生成/视频生成/代码审查 等预置模板
- 一键安装模板
- 导入/导出 Skill 配置（JSON/YAML）
- 创建新 Skill：可视化编排（拖拽工具连成DAG）

### 5. 任务管理
- 标签页切换：全部/排队/运行/完成/失败
- 表格：ID、用户、任务摘要、状态、进度条、耗时、成本
- 任务详情：DAG 可视化图、每步状态(绿/黄/红)、每步耗时
- 操作：取消/重试/下载结果
- 批量取消/重试
- 统计栏：成功率、平均耗时、总成本

### 6. 工具管理
- 表格：工具名、描述、调用次数、成功率、平均耗时
- 点击展开：参数 Schema、最近调用记录
- 启用/禁用工具
- 新增工具（上传代码或在线编辑）

### 7. 存储管理
- 文件浏览器：目录树 + 文件列表
- 按类型筛选：图片/视频/音频/文档
- 存储用量仪表盘：已用/总量、按类型分布
- 文件预览（图片/视频/音频）
- 批量删除/下载
- 自动清理规则配置
- 存储提供商切换（S3/MinIO/本地）

### 8. 模型配置
- 提供商卡片：DeepSeek / OpenAI / Anthropic / Ollama
- 每个：API Key（脱敏显示）、Base URL、状态
- 模型列表：勾选启用哪些
- 路由规则表：什么复杂度 → 用什么模型
- 默认参数：temperature / max_tokens
- 熔断器实时状态 + 手动重置

### 9. 支付计费
- 套餐卡片列表：免费/Pro/企业
- 每个：价格、功能清单、速率限制
- 创建/编辑套餐
- 支付配置：Stripe 公钥/私钥、微信支付商户号
- 订单列表：用户、套餐、金额、状态、时间
- 优惠券管理

### 10. 认证配置
- 登录方式开关：邮箱/手机/OAuth
- OAuth 配置：Google ClientID、GitHub ClientID、微信 AppID
- Session 设置：过期时间、刷新策略、单点登录
- API Key 管理：生成/吊销/权限范围

### 11. 速率限制
- 表格：套餐/用户/资源 → 限制值
- 实时用量条：当前/限制 %
- 限流日志：时间、用户、资源、触发次数

### 12. 通知配置
- SMTP 配置：服务器/端口/账号/密码
- Webhook URL 管理 + 测试按钮
- 通知模板：任务完成/任务失败/套餐到期 邮件模板

### 13. 日志审计
- 日志表格：时间、用户、操作、资源、结果、IP
- 筛选：时间范围、操作类型、用户
- 实时日志流
- 导出 CSV
- 保留策略配置

### 14. 系统设置
- 站点名称 / Logo / 主题色
- 时区 / 语言
- 数据备份：手动备份 / 定时备份 / 恢复
- 系统版本 / 检查更新

### 15. 开发者
- API 文档链接 → /docs
- Webhook 测试工具：填 URL + 事件类型 → 发送测试
- SDK 下载链接
