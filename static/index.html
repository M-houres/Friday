Multi-Page Product Shell

Friday Demo Product

这个首页代表的是“一个正式 AI 产品”的外壳，而不是单个 Skill 页面。下面的功能页和 Skill 都归属于同一个产品分组，可以继续扩成历史记录、套餐页、管理台、案例页等完整多页面站点。

当前结构

页面按用户场景组织，Skill 按后端能力组织。产品层负责把两者编排成一个完整站点。

  • 产品分组：`default`
  • 首页：`/`
  • 功能页：`/ppt`、`/legal`
  • 能力模块：一秒PPT、法务审查

What Changed
产品层成为一等公民
  • 页面属于产品 页面不再只能从 skill manifest 被动推导，也可以由 project manifest 主动声明。
  • Skill 属于能力层 一个产品可以挂多个 Skill，一个页面也可以关联多个 Skill。
  • 首页和导航独立存在 首页、介绍页、历史页这类页面不需要强绑单个 Skill。
