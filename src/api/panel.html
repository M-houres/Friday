AI 产品运营控制台

这不是技术面板，而是面向 C 端单应用经营的控制面。运营在这里看用户、任务、内容与成本；产品在这里调模板、知识库和页面流程；管理员在这里做审批、配置和版本治理。

经营总览

聚焦用户规模、交付量、待审批任务与模型成本。这里优先回答“今天这个 AI 产品跑得怎么样”，不是回答底层线程和 Redis 状态。

最近任务交付

最近结果记录

待处理审批

当前应用配置面

应用路由、场景入口与 Skill 概况，方便理解当前产品面貌。

用户列表

权益流水

操作审计

所有后台动作都需要可追溯，尤其是封禁、补偿、退款和任务干预。

支付与权益

这里承接 C 端 AI 应用最基础的商业化对象：套餐、订单和用户权益。当前先做运营可配置的第一阶段，让后台能配套餐、记订单、看额度。

套餐中心

订阅、次数包、点数包都可以抽象成套餐。当前支持基础字段与特性标签。

订单与支付

当前支持手动录入订单与到账状态，后续可接支付回调与退款流。

用户权益

先把订阅状态和额度维持起来，后面再接自动扣减与过期逻辑。

当前阶段说明

已落地 套餐、订单、用户权益三类经营对象都已可在后台维护。
下一步建议 在用户中心接入订阅状态摘要，在任务中心接入付费任务和额度扣减关联。
后续扩展 再补支付回调、退款流、优惠券、试用赠送与续费提醒。

权益流水

把发放、扣减、退款、人工补偿统一成台账，运营查账时不再只能看最终余额。

支付回调处理

用于人工补录或联调第三方支付回调，把订单推进到真实到账状态。

任务与结果

这里是当前框架最成熟的一层。把工作流、异步作业、审批和结果记录统一成“用户任务交付中心”，而不是散乱的技术视图。

模型策略配置

保存后会直接写入仓库内配置文件，新的工作流会按这里的规则选模型和回退链路。

策略接入建议

免费用户 默认便宜模型，超时或高峰时优先降级。
付费用户 功能级绑定更强模型，保底回退链路独立配置。
功能维度 对高价值页面单独配模型策略，而不是全站一个默认值。
